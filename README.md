# 关于《脑洞复盘指挥中心》项目建成并对外开放复盘的通知

各收藏夹、各 flag 遗址、各「改天一定」案卷保管处：

为深入贯彻落实「收藏不等于学会」重要指示精神，用 NASA 级严肃态度认真对待每一具脑洞遗体，经指挥中心研究决定，《脑洞复盘指挥中心》现已建成并投入运行。现将有关事项通知如下：

## 一、项目概况

本项目为 Trae 1024 创作比赛参赛作品，选定词组：**脑洞 + 复盘面板 + 五毛钱特效风**。

以报告式翻页页面，复盘那些「死于收藏夹的脑洞」。主线壳为**航天任务控制中心监控大屏**，另有病历 / 刑侦 / RPG 三条彩蛋壳藏于暗处。全程五毛钱特效：WordArt 渐变字、跑马灯、Excel 2003 风格 3D 图表、假正经 loading、CRT 扫描线、鼠标拖尾、盖章奖状，一应俱全。

## 二、核心流程

1. **假正经 Loading** —— 连接深空网络，贿赂进度条，祖传 99% 卡顿；
2. **登记表** —— 昵称 + 4 道选择题（3 道核心题 + 1 道随机加试，题库 12 道）；
3. **复盘报告（8 页）** —— 红头文件封面 / **航天监控大屏** / 数据总览（含脑洞成分雷达图）/ 死因分析 / 病程回顾 / 横向对比 / 复盘结论（含收藏家 MBTI 鉴定）/ 奖状；
4. **土味奖状** —— Canvas 生成，支持下载 PNG 与复制分享文案，盖章生效。

## 三、监控大屏（第 2 页）

戏仿 NASA 任务控制中心，深蓝科技风 + 四角包边面板：

- **存活率大数字**：红色跳动，持续下跌，抢救意义不大；
- **实时告警播报**：每 2.6 秒新增一条「刚刚又有一个脑洞失联」；
- **脑洞状态灯墙**：120 盏灯，绿 = 在轨、红 = 失联（点击查看墓志铭）、黄 = 抢救中（并没有）；
- **存活率走势**：假实时折线，稳定归零中；
- **收藏欲望仪表盘**：指针长期爆表；
- **假任务时钟**：T+ 首个脑洞死亡天数，实时走动；
- **CRT 画质拨杆**：全站扫描线 + 闪烁 + 暗角，一键回到监控室。

## 四、彩蛋系统

组织不承认以下入口的存在：

- **Konami 秘籍** `↑↑↓↓←→←→BA`：召唤「隐藏控制台.exe」（含 CRT / 音效开关）；
- **连击顶部「★」5 次**：手滑党专用，同样召唤控制台；
- **点击大屏「实时告警」面板** → 彩蛋：通缉令「下一个脑洞」（悬赏五毛）；
- **点击大屏「宇航员健康监测」面板** → 彩蛋：脑洞体检报告单（医嘱：改天再治）；
- **控制台内** → 彩蛋：RPG 角色面板（HP 执行力 3/9999，技能「改天一定」LV.MAX）。

## 五、运行方式

纯静态单页应用，无后端、无依赖、无构建。

- 方式一：直接双击 `index.html`；
- 方式二：任意静态托管（GitHub Pages / Vercel / Netlify）部署本目录；
- 方式三：本地起服务：`python -m http.server 8642`，访问 `http://127.0.0.1:8642`；
- 方式四：直接双击 `dist/脑洞复盘指挥中心-离线版.html`（单文件、零外部请求，适合 U 盘备份）。

### 演示模式（比赛现场专用）

- `index.html?demo=1`：跳过片头、隐藏固定页脚、紧凑排版，表单预填「演示员」；
- `index.html?demo=1&auto=1`：预填后自动进入报告，适合彩排与现场备份；
- `index.html?demo=2`：第二套人设「倒霉蛋」，可与 demo=1 对比演示；
- 键盘：`←` / `→`、`PageUp` / `PageDown` 翻页，`Home` / `End` 跳首尾，空格下一页；
- 片头另有「跳过片头（赶时间）」按钮，避免现场等 4 秒。

## 六、技术栈

- 原生 HTML / CSS / JavaScript，共 5 个文件，0 依赖；
- Canvas 手绘 Excel 2003 风格 3D 柱状图 / 3D 饼图 / 五边形雷达图 / 圆形公章 / 土味奖状 / 监控大屏折线与仪表盘；
- `<marquee>` 真跑马灯，拒绝 CSS 模拟，致敬经典；
- Web Audio 方波音效：按键哔、告警叮、彩蛋登场三连音；
- 确定性伪随机：同一昵称 + 同一答案组合，生成同一份报告，方便对线；
- 单文件构建：`node tools/build-single.js`，产出 `dist/` 下的离线 HTML。

```
├── tools/build-single.js              # 单文件离线版构建脚本
└── dist/脑洞复盘指挥中心-离线版.html  # 构建产物（可直接双击）
```
